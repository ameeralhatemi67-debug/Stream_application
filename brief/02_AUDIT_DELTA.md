| **S1** | **High** | **Users can self-elevate.** `profiles_update_own` and `profiles_insert_self` are row-level only (`20260821203100_row_level_security.sql`:82-89); no column guard, no new-user trigger (profiles are client-inserted). Any signed-in user can PATCH their own `is_streamer`, `is_verified`, `follower_count`, `is_currently_live`, `broadcast_type`, `active_stream_id`, `active_viewer_count` via the public anon key + own JWT. Bypasses the admin approval queue and fakes badges/live state. |

Because of S1 any user can set their own `active_stream_id` to a victim's stream id (YouTube ids are public) and moderate that chat. Fix by making live state writable only through a guarded RPC (03 P1.2). |
