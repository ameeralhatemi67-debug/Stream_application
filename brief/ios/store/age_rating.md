# Age-rating questionnaire draft

Owner completes the current App Store Connect questionnaire against the actual release and curated content. No final numerical rating is asserted. The app is not a Kids Category product and contains user-generated video/text interactions.

| Question / category | Proposed answer and evidence |
|---|---|
| Parental controls | No dedicated parent/guardian controls found. General moderation is not parental control. |
| Age assurance | No age-estimation/verification or Declared Age Range integration found. |
| User-generated content | Yes: broadcaster content, profile/organization material and chat. |
| Social media | Yes proposed under Apple's current definition: discovery/feed, following, views/reactions/chat distribute and interact with user content. Confirm in the current questionnaire. |
| Social media disabled for users under 13 | No: no age-range check or under-13 feature gate exists. Do not claim one. |
| Messaging / chat | Yes: live-room text chat and public messages. |
| Advertising | Owner verify; provisionally Yes if the embedded video provider serves paid promotion/ads. No app advertising SDK does not prove the absence of in-player ads. |
| Unrestricted web access | No arbitrary browser/address bar in the app; native navigation policy allows HTTPS YouTube/nocookie hosts only. Owner must verify actual player links, new windows and search on iOS. If those permit unrestricted browsing, answer Yes. |
| Profanity / crude humor | Owner determines frequency from actual moderated streams/chat; filtering and reporting do not prove None. |
| Horror / fear themes | Owner content review; no authored horror feature found. |
| Alcohol / tobacco / drugs | Owner content review of videos, text and live discussion; do not assume None from app code. |
| Medical / treatment information | Owner content review; educational lectures may include such subjects. |
| Health / wellness topics | Owner content review. |
| Mature / suggestive themes | Owner content review, including current catalog and user content. |
| Sexual content / nudity | Owner content review and moderation policy; no authored feature found. |
| Graphic sexual content / nudity | No intended feature; owner must ensure prohibited content is excluded and respond to reports. |
| Cartoon / fantasy violence | Owner content review; no game or authored violence feature found. |
| Realistic violence / weapons | Owner content review of educational/current-event material. |
| Prolonged graphic / sadistic violence | No intended feature; owner must ensure prohibited content is excluded. |
| Gambling / simulated gambling | No feature or payment/game mechanism found in Dart/dependencies. Proposed No. |
| Contests / loot boxes | No feature found. Proposed No. |
| Made for Kids | No. Do not add child-directed claims to name, description or screenshots. |
| Override / regional rating details | Use Apple's computed result; owner reviews territories and any justified higher override. Do not claim an implemented age gate. |

The answers for actual content frequency cannot be obtained from static source alone. Owner supplies these decisions before submission. Apple's current OS-era ratings and older-device mappings are computed in Connect; do not copy an old Play rating.

Source: [Apple age-rating definitions](https://developer.apple.com/help/app-store-connect/reference/app-information/age-ratings-values-and-definitions/), retrieved 2026-10-17. This table is app-specific assessment, not a rating awarded by Apple.
