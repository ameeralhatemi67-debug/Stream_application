# Three-city map pack: build and validation

The Spatial Map and the venue location picker draw streets and labels from
`assets/maps/tricity/`, bundled with every app release. Nothing is fetched at
run time. This folder rebuilds and checks that pack.

| File | Role |
|---|---|
| `basemap.pmtiles` | Regional Protomaps (OpenStreetMap) vector tiles, z0-15, PMTiles v3, gzip MVT |
| `style-en.json`, `style-ar.json` | Local-only styles generated by `build_styles.py` |
| `NOTICE.txt` | Data, style, font and software notices shown offline in the app |
| `manifest.json` | Byte size and SHA-256 of every file, extents, source provenance. The app refuses the pack if any file differs. |

`.gitattributes` marks the folder `-text` so checkouts never rewrite bytes the
manifest hashes.

## Rebuild (from `project/`)

```powershell
pmtiles version    # must print 1.31.2
pmtiles extract https://build.protomaps.com/<BUILD>.pmtiles assets/maps/tricity/basemap.pmtiles `
  --bbox=49.70,25.95,50.45,26.80 --maxzoom=15 --download-threads=2
pmtiles verify assets/maps/tricity/basemap.pmtiles
python tool/maps/build_styles.py
python tool/maps/validate_tricity_pack.py assets/maps/tricity/basemap.pmtiles --out <evidence>/pack-validation.json
python tool/maps/build_manifest.py   # update SOURCE in the script for a new build first
flutter test test/map_pack_test.dart test/spatial_map_test.dart
```

`extract` reads only the ranges for the envelope (about 12 MB transferred for
the current pack), never the planet file. Abort if a dry run
(`--dry-run`) reports a much larger transfer.

## What validation proves and what it does not

`pmtiles verify` checks archive structure only. `validate_tricity_pack.py`
additionally decodes **every** z0-15 tile slot in the envelope (8,298 for the
current pack) and fails on a missing slot or decode error, checks 15 named
control locations across the three cities for road features, and lists named
places for the coverage review. It cannot prove that OpenStreetMap itself is
complete or that every road carries an Arabic or English name.

No city boundary geometry is built here. City names in the app choose a map
view only (see `lib/features/map/models/map_tricity_domain.dart`).

`third_party/pmtiles/` is the upstream PMTiles Python reader (BSD-3-Clause,
see its LICENSE), used only by these scripts.
